# 逻辑谜题 · 微信小游戏样板

把现有库里同一类高质量逻辑益智，做成 **一款连贯的微信小游戏**：大厅进入 **数独、数岛搭桥、围圈数谜** 三种完整玩法。实现是 **Canvas + wx 运行时**（没有 DOM / WebView）。本目录仍是独立样板，**没有改** Android 工程、`games/*`、`manifest.json` 或任何游戏 zip，也没有新增第 501 款。

这不是已经上架的微信小游戏，也 **不承诺可以过审上架**。没有注册、登录微信，没有付费认证，没有提审或上传。`project.config.json` 里的 `touristappid` 只是微信开发者工具游客模式的占位符，**不是真实 AppID，也不是已认证账号**，不要用它声称已经真机通过。

## 小游戏还是小程序

这是一份 **微信小游戏** 工程（`compileType: game`，游戏类目）。微信里「小程序」和「小游戏」是不同形态：小游戏没有 DOM/WebView，要用 `wx.createCanvas`。选了游戏类目后不能改回普通小程序类目。官方运营规范要求介绍和类目与实际内容相符、首页呈现核心玩法、界面是完整设计而不是素材堆砌，并且禁止用动态下载脚本绕过审核。官方规范 **没有明确禁止**「同一款小游戏里做多种互补的完整玩法」；「小游戏集合」是平台广告产品，不是开发者把很多互不相关的网页塞进一个 AppID。即便如此，本样板仍按 **待审核技术样板** 提供，不保证这种形态一定能过审。

关于费用：用户提到的 **300 元是微信认证费**（企业主体，约一年有效，年审同样收费），**不是**每个玩法单独收费，也 **不能保证过审**。个人主体不能认证。本仓库不会代为注册、认证或付费。

## 为什么选这三种

对照过现有约 500 款里的逻辑益智来源，而不是按图标清单搬家。

- **数独**（原作 `games/sudoku` v8，15 关）：规则经典、关卡由 4×4 走到 9×9，带首领关，适合作为合集里的数字逻辑主轴。
- **数岛搭桥**（原作 `games/numisland`，Hashi）：和数独同属 Nikoli 风格的数字逻辑，规则互补（连边而不是填格）。原作后半段用随机种子生成，部分关卡不连通或数字为 0，不能直接冻结。本样板改为 **15 道手写并验证过的关卡**，撤销始终可用（原作撤销要商店解锁）。
- **围圈数谜**（原作 `games/slitherloop`，Slitherlink）：18 道已设计的回路谜题（2×2 到 7×7，含必经格与双回路陷阱），和数独、搭桥同属纸笔逻辑，交互是画边而不是填数。本样板补上了撤销，并拒绝让数字超额的边。

没有混入牌类、赌博、金融或动作玩法。推箱、连连看、华容道等也是优质益智，但和这三条 Nikoli 数字逻辑不如搭桥、回路来得统一，所以这一版先做三种，宁少而精。

## 和原作对齐的范围

已保留或补齐：

- 统一大厅、统一视觉和返回、各玩法自己的教学与选关
- 完整关卡：数独 15、搭桥 15、围圈 18
- 通关解锁下一关；金币（三种玩法共用）；数独仍有提示 / 加时 / 额外命升级
- 撤销（三种都有）；数独另有清除、检查、提示
- **中途进度会自动保存**。回大厅、暂停或下次打开，可用「继续本局」回到未完成的棋盘（这是对上一版「重进不能恢复局」的修复）
- 正文字号已加大（正文约 17px，说明约 15px，标题 40px），避免上一版偏小的问题

数独原作没有笔记 / 铅笔标记，这里也没有做。搭桥不使用原作那套会产出坏关的生成器。

## 本地预览（不是微信真机）

在本目录 `wechat-minigames/sudoku` 启动（不要把工作目录设到 `preview/` 再找别的入口）：

```bash
cd wechat-minigames/sudoku
node preview/server.js
```

然后打开 **http://127.0.0.1:8765/** （可用环境变量 `PORT` 修改）。

服务会把 `/` 直接返回预览页，但浏览器地址栏仍是 `/`，所以页面里的脚本使用站点根绝对路径：`/src/sudoku-app.js`、`/src/levels-data.js`、`/src/app.js`、`/preview/platform-preview.js`、`/preview/boot.js`。不要改回 `./boot.js` 这类相对路径，否则会请求 `/boot.js` 得到 404，Canvas 只剩黑色底板。`http://127.0.0.1:8765/preview/index.html` 同样可用。

浏览器里能玩，只说明共用的核心逻辑和 Canvas 布局可以在普通 Canvas 上跑。**不能**把它当成微信开发者工具或真机已经通过。页面顶部有明确提示。本预览不需要运行时付费 AI。

## 导入微信开发者工具

1. 安装[微信开发者工具](https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html)
2. 选择「小游戏」，项目目录选本文件夹 `wechat-minigames/sudoku`
3. AppID：没有正式账号时保持 `touristappid`（游客模式）；有账号后把 `project.config.json` 的 `appid` 换成你自己的
4. 用模拟器和真机预览检查触控、安全区、音频、切后台暂停与续局

`preview/`、`test/`、`screenshots/` 已写在 `packOptions.ignore` 里，导入后不应打进代码包。包内没有动态下载的脚本。

## 还没有在微信里验证的事项

- 微信开发者工具模拟器
- iOS / Android 真机触控、全面屏安全区、高 DPI
- `wx.createWebAudioContext` 是否可用（没有则静音，不影响玩）
- `wx` 存储、振动、切后台后的续局
- 游客模式以外的登录、分享、广告、支付、提审、备案、认证
- 这种「同一小游戏内多种完整逻辑玩法」能否通过微信审核（本样板不承诺）
