「游戏100」隐私政策

本政策适用于 Android 应用「游戏100」（包名 com.game100.center，以下简称“本应用”），由 【待填写：开发者名称】（所在国家/地区：【待填写：开发者所在国家/地区】，以下简称“我们”）提供。 本应用是一个合集，内含一百多款可离线玩的小游戏（HTML5 网页游戏，在应用内置的浏览器组件 WebView 中运行）。

一、概述（一句话版本）

本应用不需要注册或登录，不收集你的姓名、手机号、通讯录、位置、照片、设备标识符（IMEI、广告 ID 等）， 不包含任何广告、统计分析、崩溃上报或第三方登录 SDK。你的游戏记录只保存在你自己的手机上。

二、保存在你手机上的数据

以下数据只保存在本机的应用私有存储中，不会上传给我们或任何第三方。卸载应用或在系统设置中“清除数据”即可全部删除。

数据用途
你给游戏打的星级、收藏的游戏、每个游戏的最高分在首页展示收藏、评分和最高分
游戏自身的存档（游戏通过 WebView 的本地存储保存的进度、设置）让游戏记住你的进度
游戏列表地址、已经看过的新游戏记录同步游戏列表、标出“新”游戏
上次检查更新的时间（仅官网下载版）避免频繁检查更新
已下载的游戏文件离线畅玩

三、网络访问

不同渠道的版本网络行为不同：

  • 国内应用商店版：完全离线，所有游戏随安装包内置，没有联网权限，不会产生任何网络请求。
  • Google Play 版 和 官网下载版：为了获取新游戏，应用会从以下公共内容分发服务器下载游戏列表（manifest.json）和游戏文件： cdn.jsdelivr.net、fastly.jsdelivr.net、raw.githubusercontent.com。 官网下载版还会从同样的服务器读取最新版本信息（app.json）并下载新版安装包。

这些请求不携带任何账号、设备标识或个人信息，只包含所请求的文件地址和应用标识 Game100/版本号（User-Agent）。 与访问任何网站一样，这些服务器的运营方（jsDelivr 及其 CDN 合作方 Cloudflare / Fastly、GitHub）可能会在其服务器日志中记录你的 IP 地址和请求时间， 用于其自身的运营和安全目的，适用其各自的隐私政策： jsDelivr、 GitHub。我们无法获取这些日志。

四、“提交 bug”功能

在游戏页点“提交 bug”后，应用会用你手机上的浏览器打开 GitHub 的“新建 Issue”页面，并预填游戏编号、应用版本号和你写的问题描述。 应用本身不会发送任何内容；只有当你在浏览器里登录 GitHub 并主动点击提交，这些内容才会公开发布到 GitHub 上，此时适用 GitHub 隐私声明。请不要在描述中填写个人信息。

权限用途适用版本

本应用不申请位置、相机、麦克风、通讯录、存储、电话等敏感权限。

六、儿童隐私

本应用内容适合各年龄段，部分游戏面向儿童。由于我们不收集任何个人信息，也不包含广告和第三方追踪，儿童使用本应用时不会有个人信息被我们收集。 建议 14 岁以下（或你所在地区法律规定年龄以下）的儿童在监护人指导下使用“提交 bug”等会打开外部网页的功能。

七、数据共享、出售与跨境

我们不出售、不出租、不共享你的个人信息，因为我们根本不收集。除第三节所述公共 CDN 服务器的访问日志外，不存在向第三方或境外的数据传输。

八、你的权利

所有数据都在你的设备上，你可以随时通过卸载应用或在系统“设置 > 应用 > 游戏100 > 存储 > 清除数据”删除。由于我们不持有你的数据，没有需要你向我们申请查询、更正或删除的内容。

九、政策更新

如果本应用的数据处理方式发生变化（例如增加联网功能或第三方服务），我们会更新本页面并修改“最近更新”日期；重大变化会在应用内或应用商店更新说明中提示。
