# 全量游戏审查与修复 · 2026-10-31

基于提交 `790dedc6`，检查全部 **359 款游戏**。逐款结果、版本号和测试夹具记录见 [完整清单](game-audit-2026-10-31.json)。所有已发现的失败均在修复后复测通过。

## 会中断运行或妨碍操作的问题

- **倾斜轨道**：离线 3D 引擎没有 Mesh.lookAt，开局首帧就抛出异常。改为计算指向地球的 Euler 朝向；验证模拟持续推进且 WebGL 可以渲染。
- **忍者飞墙**：窗口缩小后沿用旧右墙坐标，绘制负宽度立体块并抛异常。缩放时同步墙坐标；统一 Pointer Events，避免触摸兼容鼠标事件重复跳跃。
- **贪吃蛇**：进入关卡前按方向键或点画布会访问未初始化的蛇和方向。输入仅在关卡运行时生效。
- **化学反应**：暂停判断使用了不存在的 play 阶段，预测、倒液与反应中均无法暂停。改为依据实际实验界面与结束阶段判断，并避免重复暂停累计错误的时间偏移。
- **存储拒绝访问**：共用存储接口捕获 SecurityError / 配额错误，保留当前页面的临时数据；34 款游戏的业务代码统一走安全接口。已有离线兜底适配器保留。浏览器不允许持久化时，刷新或重新打开可能丢失临时纪录。
- **后台运行**：98 款缺少后台处理的游戏接入原暂停动作。菜单、测验或已有暂停面板不会被切换掉；页面重新可见后保持暂停。

## 玩法与手机操作

- 恢复贪吃蛇的进阶障碍、俄罗斯方块的进阶垃圾行和记忆音符的进阶双音符规则。
- 修复键盘连续提示绕过进阶限额；仅使用 pointerdown 的重开按钮也会重置提示/撤销额度。
- 推箱子、旋转迷宫改用 Pointer Events，包含拖动捕获与取消清理。
- 修复 360px 顶栏按钮尺寸、四子棋列宽、彩色连珠格子高度、数独数字键、燃烧条件和星际快递等布局。快艇骰子将计分表改为内部滚动，13 个计分选项均可访问，页面本身不滚动。
- Windows 上统一生成内容的换行符，消除全仓“未同步”和经典生成器的误报。
