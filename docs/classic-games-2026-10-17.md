# 新增五款经典游戏

日期：2026-10-17。新增五个独立游戏目录，均为 `经典重温` 分类，版本从 1 开始。支持手机触控、键盘、暂停继续、重开、音效开关与本机最佳纪录；经典和进阶纪录分别保存。

| 游戏 | 经典玩法 | 进阶挑战 |
| --- | --- | --- |
| [四子棋](../games/connectfour/index.html) | 6×7 棋盘、重力落子、横竖斜四连；电脑会争胜、堵四，满盘可和棋 | 电脑搜索深度由四层增至六层 |
| [彩色连珠](../games/colorlines/index.html) | 9×9 棋盘，必须沿空格通路移动，同色横竖斜五连消除；不消除时新增三颗，下一批颜色可预览 | 每次新增四颗 |
| [快艇骰子](../games/yahtzee/index.html) | 五骰十三轮，每轮三次掷骰，可保留骰子；十三格各用一次，上区满63奖励35 | 每轮仅两次掷骰 |
| [宝石列柱](../games/columns/index.html) | 三珠纵列落下，换色调整顺序，横竖斜三连，重力下落可形成多次连锁；支持落点预览和直落 | 七种颜色，初始下落更快 |
| [跳格金字塔](../games/pyramid/index.html) | 七层方格全部踩亮过关，四向斜跳、敌人追逐、两次传送回顶点、失足或碰撞扣命 | 每格踩两次，初始两条命 |

快艇骰子采用单人十三轮规则，不计额外五同奖励；葫芦需恰好三同加一对，小顺子可有重复骰。金字塔使用自绘几何角色与棋盘。

## 维护与离线发布

- `scripts/classics/` 保存共用外壳和五款玩法源码，`scripts/build-classic-games.cjs` 内嵌项目共用界面与游戏逻辑，生成各游戏的 `index.html`、`meta.json`。生成文件无需请求外部脚本、图片、字体或服务。
- 改动玩法后运行生成脚本。`--check` 会检查脚本语法及生成文件是否与源码同步。后续发布已有游戏时应同时递增生成脚本中的版本及游戏元数据版本。
- 五个根目录 ZIP 仅包含 `index.html` 与 `meta.json`，清单包含包地址和实际字节数，可由现有 App 下载后离线玩。新游戏条目按 ID 排序。
- 本次提交使用 `[skip ci]`，手动生成资源包与清单，不执行 APK 编译。

## 验证

`scripts/test-classic-games.cjs` 运行真实浏览器与生产游戏代码，覆盖经典和进阶共十组：
