# 游戏100 原生界面调整

日期：2026-10-16。修改 Android 源码，未执行 Gradle、APK 编译或模拟器构建。

[打开交互设计预览](app-ui-preview.html)。预览用于确认配色与排版，是浏览器中的设计参考，不是 APK 截图；示例操作不修改 App 数据。

## 视觉方案

以游戏库为主体，精选卡片保留深色游戏舞台，其他区域降低装饰密度，优先显示游戏、分类和开玩入口。

| 用途 | 颜色 |
| --- | --- |
| 页面背景 | `#F3F6FB` 雾蓝 |
| 内容表面 | `#FFFFFF` 白色 |
| 正文与标题 | `#182B49` 深蓝 |
| 主要操作 | `#285FE8` 游戏蓝 |
| 精选舞台 | `#182E4E` 藏蓝 |
| 精选提示 | `#B9E9D6` 薄荷色 |

使用系统无衬线字体，以 26sp 页面标题、20sp 分组标题、16sp 游戏名及 12–15sp 辅助信息建立层次。主要操作至少 44dp 高，详情评分使用 52dp 触控区域。

首页结构：标题与工具 → 搜索 → 横向分类 → 精选推荐 → 游戏数量与列表。搜索或分类生效时收起精选区；无结果时提供清除筛选入口。

## 具体改动

- 首页：前置搜索，重做分类选中态、精选卡片、游戏列表、下载/更新/开玩状态，补充数量与空结果反馈，保留搜索状态。
- 详情：补充原生返回栏，使用圆角浅色图标底，重排开始、收藏、简介及个人评分区域；收藏和评分增加明确的选中态与无障碍说明。
- 设置：补充返回栏，按内容来源、离线说明、版本及下载管理分组，统一主按钮、次按钮和清除按钮。
- 公共样式：统一颜色、边框、字阶、按钮反馈、状态栏图标及启动图标配色；下载弹窗增加清晰的进度层次。
- 游戏页：补齐已有 Kotlin 逻辑引用的反馈按钮，避免布局缺少 `bug_button`。
