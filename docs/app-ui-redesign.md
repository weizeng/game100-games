- 实验室同时读取本机已安装数据和首页已有远端缓存，避免仅依赖进程缓存导致离线或页面重建后看不到本机实验；加载与空状态分别显示。
- 预览从全部 201 份游戏元数据生成列表，包含 50 个实验，支持更多推荐、进入实验室、学科筛选、返回和实验详情演示。数据和下载状态仅作设计展示，不修改 App 数据。

## 视觉方案

以游戏库为主体，精选卡片保留深色游戏舞台，其他区域降低装饰密度，优先显示游戏、分类和开玩入口。

| 用途 | 颜色 |
| --- | --- |
| 页面背景 | `#F3F6FB` 雾蓝 |
| 内容表面 | `#FFFFFF` 白色 |
| 正文与标题 | `#182B49` 深蓝 |
| 主要操作 | `#285FE8` 游戏蓝 |
| 精选舞台 | `#182E4E` 藏蓝 |
| 精选提示 | `#B9E9D6` 薄荷色 |

使用系统无衬线字体，以 26sp 页面标题、20sp 分组标题、16sp 游戏名及 12–15sp 辅助信息建立层次。主要操作至少 44dp 高，详情评分使用 52dp 触控区域。

首页结构：标题与工具 → 搜索 → 横向分类 → 精选推荐 → 游戏数量与列表。搜索或分类生效时收起精选区；无结果时提供清除筛选入口。

## 动效补充（2026-10-16）

精选卡片成为动态的游戏舞台：双层轨道、旋转光点、微光、周期流光和上下 4dp 的图标悬浮。按下卡片时根据触点产生最多 4° 的轻微倾斜，松开或滚动取消时回正。

- 首页内容用一次入场建立层次，前六个游戏图标错峰出现；分类切换更新结果并回弹选中项。
- 列表、分类和操作按钮增加 90ms 按压、320ms 回弹，不延迟点击，不接管滚动或长按。
- 新增收藏时爱心弹跳并散开八颗小粒子，取消收藏只更新状态；评分时已点亮的星星依次弹起。
- 详情和设置增加短暂入场，搜索框在浏览器预览中补充聚焦反馈。
- 原生精选舞台在移出可见区域、失去窗口焦点、页面隐藏或销毁时停止动画；收藏粒子结束或控件移除后释放。系统动画关闭时呈现静态界面。
- 预览同步主要动效，提供“重播入场”；页面隐藏或精选移出视口时暂停轨道，遵循 `prefers-reduced-motion`，预览交互不修改 App 数据。
