# 每日新游戏 2026-10-28（10 款）

10 款都是单文件离线 HTML5（`games/<id>/index.html` + `meta.json`），studio **Grok**，皮肤 B「霓虹糖果 / Pop Arcade」+ `GameUI.fx`。竖屏触控、Pointer Events，390×844 / 360×640 不滚动。

每款都有：首玩教程、15 关/星级、成长解锁（`g100_<id>_prog`）、Boss 或特殊关、暂停/重开、计分与最佳纪录、Web Audio 静音、切后台自动暂停、按钮 ≥44px。

本批覆盖未重复品类：六边叠塔 / 落沙成画 / 归位小家 / 圈地争锋 / 人潮闸门 / 水果黑洞 / 弹球深渊 / 阶段牌局 / 三峰纸牌 / 疯八出牌（对应 backlog #13–#22）。
