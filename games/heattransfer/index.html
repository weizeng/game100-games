🔥 热传导

玩法说明

1. 共 3 轮，每轮指定一种棒料（铜 / 铁 / 木），请按任务要求选好材料。
2. 先预测右端升到 60℃ 要多久：快（<10秒）、中（10-25秒）、慢（>25秒），答对 +20 分。
3. 点「开始加热」，看热量从左端一节节传向右端，计时到 60℃ 停止并记入实验记录。
4. 可打开「红外视角」查看每节实时温度，加热功率三档可调。

原理简介

热总是从高温处传向低温处。不同材料导热能力差别巨大：铜是热的良导体，木头几乎不导热。

实验结论

热量从加热端向低温端逐节传递，右端升温用时：铜（快）＜ 铁（中）＜ 木（慢）。材料不同，导热能力差别巨大——这就是做锅用金属、做锅柄用木头的原因。

知识点
Q = c m ΔT（吸放热公式）

金属多为热的良导体，木材、空气等为热的不良导体。热传导是固体中主要的传热方式。
