# 御空守夜

独立 Three.js + Vite 离线游戏，复用月海旅人的程序化几何、平涂材质及描边后期。

在本目录运行 npm ci、npm run dev 开发；npm run build 生成 games/skywarden/index.html 并同步标准 UI。推荐 Node 18+。所有代码、着色器和许可内联，无外部资源。

WASD / 摇杆移动；拖动画面转向；E 起飞/降落；Space 或上升按钮升空；Q 或下降按钮降低高度；R 在南岸码头登舟或在水面从飞行切换到灵舟；靠岸后 R 下船；F 灵爆。自动攻击 52 米内最近敌人。陆地不能驾舟，水面不能步行。飞行最高 90 米，区域边界有限。

每轮昼夜 180 秒，四阶段各 45 秒：日出收集三枚空中灵晶修复生命和灵核，白昼清剿升级，日落抵御攻击中心灵核的怪物，夜间迎战蚀日巨灵。击杀五个敌人提升一级，灵爆冷却八秒。生命或灵核归零结束。一日远征击败 Boss 获胜，无尽生存跨日继续且敌人强度和数量递增。两模式分别保存最高积分。

主画布使用 renderer.setPixelRatio（最高 1.5）高清渲染；GameUI.fx 在内存中绘制灵核标记，有无 FX 回退。敌人上限限制负载，仍需实机测帧率。景观塔楼/天桥暂不支持攀爬，飞行碰撞采用地形高度约束，非完整物理世界。无联网或多人功能。

node verify.mjs 用仅存在于测试构建的注入接口检查移动状态、采集、昼夜、Boss 胜利、跨日、失败及重开，正式产物仅保留只读诊断对象。仓库 check-game 两种手机尺寸通过。全仓经典游戏生成检查仍因既有 connectfour 源码/生成文件不同而失败。
